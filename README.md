# Retail Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze retail sales performance, profitability, product performance, and discount impact.

## Dashboard Pages
- **Retail Sales Overview:** Key performance indicators, monthly revenue trends, regional sales, and category performance.
- **Product Analysis:** Top and bottom 10 products by revenue, sub-category sales, and segment analysis.
- **Profitability Analysis:** Profit margins, discount versus profit, and sub-category profitability.

## Tools Used
- Microsoft Power BI
- DAX
- Sample Superstore Dataset

## Key Metrics
- Total Revenue
- Total Profit
- Total Orders
- Profit Margin
